# Market Microstructure

## Project Goal
We aim to build a simulation of a Limit Order Book (LOB) with a discrete-event, tick-driven simulation using LOBSTER ITCH data. This model includes several market makers interacting covering latency, inventory, and adverse selection. We also incorpoerate order flow simulation, inventory-based quoting, and mecahnics of execution.
